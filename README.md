# Verifier Distillation Tracker

A research log for newly published work on verifier distillation and closely related directions.

## Scope

- Verifier and reward-model distillation
- On-policy and distributional distillation
- Generative and distributional verifiers
- Ordinal probabilistic reward models
- Applications to long-horizon agent trajectory evaluation

New paper notes are stored under `research/verifier-distillation/`. Each note records the source, core method, evidence quality, relationship to prior work, and implications for the Agent verifier × OPD research plan.
