# Verifier Distillation Research Log

Automated notes are added only when a newly surfaced paper is highly relevant to verifier distillation or the Agent verifier × OPD research direction.

## File naming

`YYYY-MM-DD-paper-slug.md`

## Required sections

1. Paper metadata and direct links
2. What is genuinely new
3. Core method
4. Evidence quality and limitations
5. Relationship to the closest prior work
6. Relevance to LLM-as-a-Verifier
7. Implications for the Agent verifier × OPD experiment plan

Before adding a note, check existing files by arXiv ID, DOI, canonical paper URL, and normalized title to prevent duplicates.
