# PIVOT：通过在线教师纠正进行渐进式干预

## 一句话结论

PIVOT 说明，在全失败、终局 verifier 无法区分轨迹的困难状态，仅给教师轨迹或仅做 token KL 都不够；“教师及时改写学生轨迹 + 对改写片段做稠密蒸馏”才同时提高成功轨迹可达性和可学习性。

## 真正新增的内容

**论文原文结论**：

1. 将教师信号拆成两种互补机制：轨迹级干预负责把学生带到可获奖励的状态，token 级监督负责让学生真正吸收教师插入的决策。
2. PIVOT 在学生 rollout 中插入教师生成的纠正片段，并在 RLVR 目标之外对这些片段施加 KL 监督；论文还系统比较干预位置与监督方式。
3. 在 Survo 的受控实验中，哪怕提供正确解答的 oracle prefix，仅让学生续写的 avg@8 与 pass@8 仍低于 1%；直接监督该前缀后才明显改善。

**分析推断**：

- 这比“先生成整条教师轨迹再蒸馏”更接近长时程 Agent 的局部恢复：只在 verifier 发现不可恢复偏离时插入短纠正，并把纠正后的 student continuation 保留为 on-policy 数据。
- 对 Agent verifier × OPD，干预点可由环境真值、状态约束或高置信失败证据触发，而非由同一个 LLM Judge 自行闭环决定。

## 核心方法

1. 学生先按当前策略生成，遇到预定干预点后由强教师产生短纠正片段。
2. 学生从纠正后的前缀继续生成，使轨迹仍包含大量 student-generated states。
3. 用可验证终局奖励训练完整轨迹；同时仅对教师插入片段施加 token-level KL。
4. 论文比较不同干预时机、教师片段和监督目标，区分“进入好轨迹”与“学会好动作”两种效应。

## 关键实验结果

**论文报告**：在困难逻辑游戏与数学推理基准上均优于已有方法；逻辑游戏 mean avg@8 从最佳基线的 19.5% 提升到 35.6%，接近翻倍。项目页进一步强调，单纯提供高质量前缀仍可能无法被学生独立复现。

## 证据质量与局限

- **优点**：有受控机制拆分，不只报告最终分数；终局信号来自可验证奖励，减少纯 Judge 自洽偏差。
- **局限**：主要是数学/逻辑推理，尚未证明对带工具副作用、部分可观测和超长时程 Agent 同样有效。
- 教师干预本身可能改变状态分布；若训练和评测共用教师或 verifier，仍可能产生 evaluator 共适应。
- 项目页区分训练奖励曲线与测试准确率，避免把训练信号改善误当泛化结论；但公开摘要未给出完整成本与统计区间。

## 最接近的相关工作

- **ATI-OPD**：同样在首次高分歧处插入教师片段，但更强调长序列漂移和 suffix loss 过滤。
- **AC-OPD / PACT / γOPD**：分别处理自适应教师 continuation、critic-policy 对齐和时间信用。
- **RLVR / GRPO**：PIVOT直接补足全失败组没有相对奖励的盲区。

## 如何复用或推进 LLM-as-a-Verifier

可让 verifier 输出四元组：`(首个可证失败步骤, 失败证据, 最小纠正片段, 可恢复性)`。只有环境测试、程序断言或多源证据确认失败时才允许插入；教师片段只做局部 KL，后续由学生重采样。这样生成的 critique state 应绑定原始 observation 与可复现证据，不能只保存自然语言判断。

## 对 Agent verifier × OPD 实验路线的具体影响

- **score-level OPD**：将“轨迹总分”改为“硬真值终局奖励 + 局部教师片段 KL”的双通道基线。
- **pairwise A/B/T 与序数分布**：在同一分叉比较原学生、教师纠正后续和替代纠正；证据不足标 T，避免强行排序。
- **程序化/环境真值门控**：只在测试失败、约束违背或状态不可达等可重放事件触发教师。
- **student-generated critique states**：保留教师纠正后的学生续写，训练 verifier 判断是否真正恢复，而非只判断纠正文案是否好看。
- **高熵分叉与探索**：干预限于已证实的坏分支；对多个可行分支不做单一路径模仿。
- **sealed eval**：冻结未参与训练的任务、环境快照和 verifier；分别报告“无教师部署”和“允许教师干预”两种结果。
