## 一句话结论

OmniOPD 为闭源 teacher 和跨 tokenizer 场景提供了 chunk-level、logit-free 的 OPD 替代方案。

## 真正新增的内容与核心方法

用 teacher Monte Carlo rollout 与多 token chunk 的连续语义相似度近似局部偏好，只在 student peak-entropy 分叉审计；Dirichlet-Multinomial prior 与 base-model KL anchor 控制采样方差和坍缩。

## 关键实验、证据质量与局限

数学任务最高比标准 OPD 高 28.64%；使用 Claude-4.5-Haiku/Gemini-2.5-Flash 等黑盒 teacher 又比开放 teacher 高 9.54% 相对收益。代价是多次采样与语义度量，成本和评估器偏差需独立核算。

## 与 LLM-as-a-Verifier 及 Agent verifier × OPD 的关系

如果强 verifier 只能返回文本或分数而无 logits，可在高熵 critique/tool-choice 分叉调用它。建议与固定频率调用、全 token logits、score-level API 蒸馏比较单位收益/API 成本。
